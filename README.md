# よりみちコンディショニング

埼玉県本庄市児玉町のコンディショニングサロンのサイト。1ページ完結の静的HTML。

- **ビルド不要。** `index.html` を編集するだけ。
- CSSはHTML内にインラインで入っている。外部CSSファイルはない。
- Claude Codeで作業する場合は、先に `CLAUDE.md` を読むこと。**使ってはいけない言葉のリストがある。**

---

## ローカルで見る

`index.html` をブラウザにドラッグするだけで開ける。

サーバー経由で確認したい場合：

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Vercelにデプロイする

1. [vercel.com](https://vercel.com) にGitHubアカウントでログイン
2. 「Add New」→「Project」→ このリポジトリを選ぶ
3. Framework Preset は **Other**（静的サイトとして扱われる）
4. Build Command と Output Directory は**空のまま**でよい
5. Deploy

以降、`main` にpushすると自動でデプロイされる。

独自ドメインは Vercel の Settings → Domains から追加する。

**現在の公開URL：** https://yorimichi-gamma.vercel.app/

> `vercel.json` で `framework: null` を固定してある。これが無いと Vercel が Next.js と誤検出してビルドが落ちる。ダッシュボードの設定より優先されるので、このファイルは消さないこと。

## 写真を差し替える

`images/` の中のファイルを同じ名前で上書きする。

| ファイル | 用途 | 推奨サイズ |
|---|---|---|
| `hero.jpg` | ヒーロー | 幅1500px前後 |
| `land.jpg` | フッター下の風景 | 幅1600px・横長 |
| `ogp.jpg` | SNS共有時のサムネイル | 1200×630 |

**引きの画は使わないこと。** 施術スペースはデイサービスの設備が写るため、手元のクローズアップで構成する。

> ヒーローを差し替えるときは、被写体の顔が**フレームの上から3割あたり**に来る構図だと文字と干渉しない。スマホでは写真の下部に、PCでは左半分にコピーが乗る。

## 予約の仕組み

**枠取りは Googleカレンダーの「予約スケジュール」** を使う。無料アカウントで使え、空き枠が自動で表示され、その場で確定し、確認メールも自動で届く。
「〇日空いてますか」の往復が消えるのが最大の理由。営業時間（18–21時）は施術中で返信できないため、自動確定でないと機会損失になる。

### 設定手順

1. **事業用のGoogleアカウントを新しく作る**（個人の予定が入っているアカウントは使わない。予定と衝突して枠が勝手に閉じるため）
2. Googleカレンダーで「作成」→「予約スケジュール」
3. 予約枠の長さ：**30分**
4. 提供時間：**月・水・金・日 18:00–21:00**
5. 直前予約の締切：**2時間前まで**（当日の飛び込みを防ぐ）
6. 予約可能期間：**30日先まで**
7. カスタム質問に以下を入れる（ここで最低限の安全確認を取る）
   - 初めてですか／2回目以降ですか ← **料金が変わるので必須**
   - お困りの場所
   - **急なケガですか（はい／いいえ）** ← 「はい」なら整形外科を案内する
   - **医師から言われている病名**（骨粗しょう症・椎間板ヘルニア・脊柱管狭窄症など）
8. 確認メール・リマインドをONにする
9. 生成されたURLを `index.html` の `#reserve` に入れる

### 初回問診（Googleフォーム）

予約確定後の案内としてリンクを送る。回答はスプレッドシートに溜まるので、そのまま台帳になる。
**サイトには載せない。** サイト上の導線は「予約＝カレンダー」「相談＝LINE」の2本に絞ってある。

## 初回問診フォームに入れる項目

Googleフォームを作るときは、最低限これを入れる。

- お名前／ふりがな
- 電話番号
- ご希望日時（第2希望まで）
- 初めてか、2回目以降か ← **料金が変わるので必須**
- お困りの場所
- 急なケガかどうか ← **「はい」なら整形外科を案内する**
- 医師から言われている病名（骨粗しょう症・椎間板ヘルニア・脊柱管狭窄症など）
- 現在治療中の病気・服薬

下の2つは、首を鳴らさない・禁忌に矯正をかけないという約束を実行するための情報。**省かないこと。**

「どこで知りましたか（チラシ／口コミ／Google／Instagram／TikTok）」も1問足しておく。流入経路が分かると、どこに力を入れるべきかが判断できる。

### スプレッドシートで見る数字

- 新規数／月
- **2回目転換率（目標60%以上）** ← 最重要
- 平均来店回数
- 初回から2回目までの日数
- 客層の内訳（学生・施設職員・主婦・力仕事）
- 流入経路

### 注意：要配慮個人情報

病名や服薬は「要配慮個人情報」にあたる。取得には本人の同意が必要で、**プライバシーポリシーの掲示が実質必須**。
スプレッドシートの共有設定を「リンクを知っている全員」にしないこと。
